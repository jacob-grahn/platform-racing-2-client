# Mobile UI fonts

- `LilitaOne-Regular.ttf`: [Google Fonts / Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone), with `LilitaOne-OFL.txt`.
- `Nunito-Bold.ttf`: static weight 700 instance of [Google Fonts / Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), with `Nunito-OFL.txt`. Generated using fontTools `varLib.instancer`; names normalized to `Nunito` (family), `Nunito Bold` (full name), and regular style. OpenFL resolves the full name, using the supplied bold outlines without synthetic bolding.

Downloaded September 20, 2026. These fonts are packaged only in mobile and preview
builds. The title continues to use the original `assets/fonts/gwibble.ttf`.
